# Bloques de código {#bloques-de-codigo}

Un bloque de código se muestra con su resultado. Este es un ejemplo en español de una página traducida.

## Un encabezado con id {#encabezado-con-id}

Un bloque de texto con una línea que empieza por `# ` y lleva un id entre llaves. Su texto no cambia.

```text
# Un comentario {#no-es-un-id}
```
